# Task assist-01: summarize docs into memory

Read `docs/` and write `MEMORY.md` with: a 5-line summary of the project,
a bullet list of key terms, and an open-questions section. Use plain ASCII
markers ([OK], ->) instead of emojis.

## Acceptance criteria
- `MEMORY.md` exists with the three sections
- Mentions the product name and at least 3 key terms from the docs
